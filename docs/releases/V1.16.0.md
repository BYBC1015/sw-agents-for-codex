# SW V1.16.0 / Canvas 0.4.0

Released source: 2026-10-20.

Storyboards now retain editable shot records, exact reusable-asset versions and selected outputs. A shared wardrobe/character/scene change identifies affected shots without automatically regenerating them. A camera-only change appends one shot version and preserves unrelated shots; prior versions can be selected again.

Canvas is bundled under `apps/media-canvas` with a portable launcher, local storage configuration, browser UI, CLI, HTTP and on-demand WebMCP operations. The default project summary stays compact. Existing Windows project locations are reused when present. No project databases, client media, private keys, generated payloads or runtime caches belong in this release.

Banana accepts `--lock-file` from a Canvas shot packet. Protected constraints survive compression and empty-result retry; outdated dependencies and insufficient constraint budgets fail before paid calls. Retry no longer unconditionally forbids text requested by the user.

Visual reviews attach evidence to an exact shot version. Draft manifests show blockers; reviewed manifests require outputs, current dependencies and passing recorded review. This is review tracking, not automatic image recognition. JSON manifests are provided; PDF rendering and film-shot reference search remain future work.

The source package also carries the already-established local V1.15 Kling API/Hermes runtime dependencies, which had not yet been included in the previous GitHub branch. Unrelated Kling batch-app work is excluded. A Windows ACL-output decoding issue found in regression checks was corrected.
