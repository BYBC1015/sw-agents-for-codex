# Aesthetic Expansion Queue - 2026-05-25

This file expands SW's top-tier aesthetic library with curated targets for future image/contact-sheet collection. It intentionally stores source lanes, selection reasons, and prompt-safe lessons rather than raw images.

## Curation Rule

- Add a target only if it teaches a reusable visual decision: composition, light, blocking, material, color, edit rhythm, typography, or production-design logic.
- Prefer 1-3 excellent references per visual problem over a large unfocused dump.
- When raw images are collected later, store them under ignored `images/` folders and keep tracked notes source-neutral.
- Do not prompt AI tools to copy named works, exact frames, title cards, logos, character designs, or proprietary layouts.
