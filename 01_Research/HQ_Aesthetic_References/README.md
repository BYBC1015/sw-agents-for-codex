# HQ Aesthetic References

Local-only high-resolution visual study library for SW.

Tracked files in this folder are indexes and usage rules. Image files and contact sheets are ignored by Git by default so the repository stays lightweight and source-safe.

## Indexes

- `HQ_Aesthetic_Master_Index.md`: master entry for all HQ aesthetic references and low-token selection.
- `Aesthetic_Decision_Index.md`: compact profile layer for automatic SW visual-taste decisions.
- `Aesthetic_Library_Config.md`: storage portability and environment-variable rules.
- `Top_Tier_Collection_Queue.md`: future high-quality collection lanes and standards.
- `Aesthetic_Expansion_Queue_2026_05_25.md`: curated 74-target expansion queue for future collection.
- `Interactive_Aesthetic_Browser_Tech_Notes.md`: planning notes for a future local image viewing, rating, and filtering system.
- `Oscar_HQ_Frame_Set.md`: 30-film Oscar companion set.
- `Open_HQ_Aesthetic_Study_Set.md`: open-license high-resolution visual study set.
- `Film_HQ_Reference_Set_2026_05_24.md`: 50-film batch covering Dune / Denis Villeneuve, Jia Zhangke, Oscar Best Picture add-ons, and Oscar Animated Feature winners.

## Use Rule

- Use HQ and medium frames for close study: composition, lens feel, blocking, light, texture, palette, atmosphere, and rhythm.
- For default style decisions, use `Aesthetic_Decision_Index.md` first instead of loading image indexes.
- Do not copy exact frames into deliverables.
- Convert references into source-neutral visual language before using image or video generation tools.
- Replace fallback or single-image rows over time when better sources are found.
- If the raw image library moves to another disk, keep tracked indexes unchanged and set the portable root variables described in `Aesthetic_Library_Config.md`.
