## Use Rule

- Use this set for close visual study and prompt-language extraction, especially texture, light, spatial depth, and natural color relationships.
- Check each Commons source page before external publication if a specific image is reused directly.
- For SW generation prompts, extract visual language only; do not ask models to reproduce a specific Commons file.
