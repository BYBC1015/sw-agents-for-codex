## Use Rule

- This is a study and prompt-calibration library, not a client asset library.
- Study close details from HQ/medium frames: lens feel, frame density, color separation, skin/light behavior, set texture, blocking, atmosphere, typography/graphic treatment when visible.
- Do not ask AI tools to copy a named film frame. Translate references into source-neutral visual language.
- MUBI rows usually provide one high-quality representative still; FilmGrab rows usually provide several frame references.
