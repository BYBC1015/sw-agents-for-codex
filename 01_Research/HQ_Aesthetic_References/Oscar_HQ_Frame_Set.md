## Use Rule

- Use this set for personal visual study, mood calibration, and prompt-language extraction.
- Do not copy exact frames into client deliverables. Extract composition, lens feel, subject scale, light direction, contrast, color relationships, set texture, blocking, and rhythm.
- Prefer `HQ` and `medium` frames for detailed study; use `fallback-small` only for historical coverage until a better source is found.
- Keep generated prompts source-neutral. Example: use `low-key side light, face half-submerged in warm shadow, restrained interior blocking`; do not use `copy The Godfather frame`.
