## Use Rule

- Use the contact sheets for local taste calibration only.
- Do not commit the image folders or contact sheets unless the repository is explicitly private and the user accepts that risk.
- For SW output, convert each reference to camera, light, composition, texture, palette, blocking, and rhythm language.
- Alternate-source rows are labeled `ok-alternate`; do not silently mix source types.
