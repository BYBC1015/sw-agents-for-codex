## Extraction Rule

Use these references as a taste signal, not as assets to reproduce.

Good extraction:

```text
large negative space, restrained neutral background, one tactile object casting a soft shadow, offset composition, quiet editorial mood, no copied layout or source text
```

Bad extraction:

```text
copy image 08 exactly
```

## SW Usage

Read this file only when the user mentions:

- daily selected
- aesthetic material
- aesthetic reference
- moodboard
- visual reference
- today's added references

Do not read or summarize all extracted images during normal project startup. Pick only the relevant date or contact sheet, then turn selected observations into compact prompt language.
