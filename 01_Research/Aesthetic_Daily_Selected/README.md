# Aesthetic Daily Selected

This folder stores the lightweight index for user-supplied daily aesthetic references.

The extracted images and contact sheets are kept locally under ignored folders:

- `images/`
- `contact_sheets/`

Do not commit the extracted images by default. Use them as an internal moodboard source and convert them into neutral visual language: composition, lighting, color relationships, material behavior, framing, rhythm, typography space, and anti-AI-look details.

When using these references in SW:

1. Read `Daily_Selected_Index.md` first.
2. Pick one or two visual levers, not a pile of images.
3. Do not copy logos, exact layouts, proprietary graphics, identifiable people, or source text.
4. Translate the reference into prompt-safe wording before using Banana Pro, Seedance, or any other generation tool.
5. Keep the user's project brief primary.
